# nbatotals

Work in progress. A transparent pace × efficiency NBA totals engine and a
backtest harness built so that it cannot flatter itself.

The hypotheses and expected results were written down before any backtest:
see [docs/PREREGISTRATION.md](docs/PREREGISTRATION.md). The local data schema
is in [docs/schema.md](docs/schema.md).

MIT licence. No fetched data is, or will be, committed to this repository.
